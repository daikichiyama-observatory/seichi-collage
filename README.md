# 圣地巡礼拼图

离线图片拼接工具。Mac 上用浏览器打开 `index.html`；iPhone 上打开部署后的网页并添加到主屏幕。两端共用同一份代码，可导入动画或漫画图片与实景照片、调整裁切、拼接并导出。

所有图片只在本机浏览器中处理，不会上传到网站。Mac 本地使用不需要安装依赖或启动服务器。iPhone 主屏幕和离线功能需要首次通过 HTTPS 网页打开，成功加载后会缓存程序文件；图片本身不会被缓存。

## 使用

1. 导入动画截图或漫画图片，拖出需要对比的区域。
2. 导入实景照片，在等比例的框中拖动、用滚轮、双指或滑杆缩放，直到取景合适。
3. 选择动画图的位置、边框和分隔线。可按原始尺寸导出，或选“适合分享”将长边限制在 4096 px、总像素限制在 1200 万以内。
4. 下载 PNG/JPEG；在支持文件分享的浏览器中，也可直接使用“分享 JPEG”。

## iPhone 使用

将本仓库中的静态文件部署到 HTTPS 地址，在 Safari 中打开，点“分享”→“添加到主屏幕”。在程序中点“选择图片/照片”，从照片图库选择。完成拼图后点“分享 JPEG”，即可使用系统分享菜单；如分享不可用，程序会下载 JPEG。首次安装和不同 iPhone 型号的大图导出仍需实机验证。

不应直接将私有仓库改为公开。代码仓库可保持私有；网页地址的访问范围由所选部署方式单独决定。

导入后会显示浏览器实际收到的图片像素尺寸和文件大小。若从 macOS“照片”App 直接拖入的图片分辨率过低，请先在“照片”中导出大尺寸图片，再从 Finder 拖入。

目前支持浏览器能够解码的 JPEG、PNG、WebP 和 HEIC/HEIF 图片；格式支持取决于所用浏览器。暂不支持 GIF 动画、视频及透视校正。
